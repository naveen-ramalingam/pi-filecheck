# Pi FileCheck v0.1.0

Initial pre-1.0 release: a terminal menu, persistent scan locations and mount guards,
read-only archive tests, multipart grouping, SHA-256/reference comparisons, JSON,
CSV and detailed reports, and a conservative per-user installer.

Built-in ZIP/TAR/gzip/bzip2/xz checks work without runtime dependencies. Installed
7-Zip/UnRAR/zstd/lz4 extend format support. No extraction, repair, device operations,
network submission or firmware execution occurs. Sony/PS5-specific files return
UNKNOWN when no integrated full test exists. Linux raw exFAT image checks use only
verified exfatprogs in no-repair mode; physical-device diagnostics remain manual.
A digest alone is not
an integrity or authenticity verdict.

Python 3.11+; intended for Debian ARM64 on Raspberry Pi 5. See
[test evidence](../testing.md) for tests actually run and remaining hardware work.
This is not a 1.0 stability or Raspberry Pi hardware certification claim.
